Saving Your Config

Your data lives in your browser's localStorage. It doesn't follow you across devices, and it gets wiped if you clear your browser data or open the tracker from a new URL (like after pushing to GitHub Pages).

1
Export before you push

Click the Export button. It downloads a tracker-config.json file with all your activities and entries.

2
Push your code

Push to GitHub as normal. Your tracker will be live at your GitHub Pages URL.

3
Import after the push

Open the live site, click Import, and select the JSON file you downloaded. Everything comes back — activities, entries, counters, order.

Checkboxes are not saved in the export — only your activity structure and entries. This is intentional so you always start fresh after a deploy.
